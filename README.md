# 📱 星星小手机

给你的角色装一部小手机。

在酒馆右下角点开悬浮球，就是一部完整的手机：会话列表、和角色一对一聊天、自己加 NPC、
拉群聊、刷朋友圈。消息不只是文字，还能发语音条、转账、外卖、定位、天气这些卡片，
配 32 个手绘表情包。手机里聊过的内容还能回流到主线剧情里，角色不会装作不知道。

---

## 安装

酒馆 → 扩展（插头图标）→ **Install extension** → 粘贴：

```
https://github.com/STAR-JIAN2/starstar-phone
```

装完刷新页面，右下角出现一个圆形悬浮球，点它就打开了。

> 如果你之前手动放过这个扩展的文件夹，**先把那个文件夹删掉**再装，否则会撞名字。
> 扩展目录在 `data/<你的用户名>/extensions/`（旧版酒馆是 `public/scripts/extensions/third-party/`）。

想更新的时候，在扩展列表里点这个扩展的 **Update** 按钮就行。

## 界面

底部三个标签：**聊天**、**朋友圈**、**设置**。

### 聊天

点「聊天」先看到的是**会话列表**，点某个人才进对话界面。主角色永远排在最上面，
其他人按最后一条消息的时间排。

| 位置 | 作用 |
|---|---|
| 列表右上角 **＋** | 加联系人 / 发起群聊 |
| 列表里每行右边的 **✕** | 删掉这个联系人（连聊天记录）|
| 聊天界面左上角 **‹** | 回列表 |
| 聊天界面右上角 **⋯** | 这个人的专属设置 |

在聊天界面里：

- 输入框打字，**回车发一条**，可以连发好几条
- 点右边的 **➤** 让对方回复
- 鼠标停在某条消息上会出现 **✕**，可以删单条
- 悬浮球可以拖到屏幕任意位置

### 加联系人

列表右上角 ＋ → **👤 加一个联系人**，填名字、在线状态、头像链接、人设。

嫌麻烦就点 **✨ 让 AI 想一个** —— AI 会照着当前剧情编一个名字、状态和人设填进表单，
你改一改再点创建。

人设这一栏很重要：TA 回复的时候，这段会喂给 AI，决定 TA 是谁、怎么说话。

### 群聊

列表右上角 ＋ → **👥 发起群聊**，勾选谁进群，取个群名（不填就用成员名字拼一个）。

群里每条消息都标着是谁说的，头像也是各自的。让群里的人接话时，所有成员的人设会一起
喂给 AI，可以只有一个人说，也可以几个人你一言我一语。

群头像不设的话，自动用成员头像拼一个九宫格。进群聊的 ⋯ 可以随时加人踢人。

### 朋友圈

- 右上角 **＋** 自己发一条
- 右上角 **TA** 让角色按当前剧情发一条
- 每条下面能点赞、评论
- 自己发的那条有个「**让TA看**」，角色会决定要不要点赞或评论

配图直接在正文里写描述：`[窗外的晚霞]`，可以写好几个。写的如果是表情包的名字，
会直接显示那张表情。

## 功能卡片

聊天界面输入框上方那排图标，点一下会把模板填进输入框，你改完再发。也可以直接手打。

| 想发什么 | 怎么写 | 效果 |
|---|---|---|
| 语音 | `[语音：8"\|这里是语音内容]` | 语音条，点开显示文字 |
| 撤回 | `[撤回：这条被撤回了]` | 「撤回了一条消息」，点「查看」能看到原文 |
| 链接 | `[链接：标题\|描述]` | 链接卡片 |
| 外卖 | `[外卖：菜名\|已买单]` | 外卖订单卡片 |
| 代付 | `[代付：商品\|¥38.00]` | 代付请求卡片 |
| 转账 | `[转账：520\|拿去花]` | 转账卡片 |
| 收款 | `[转账：520\|收下啦\|收]` | 显示成「已收款」|
| 退还 | `[转账：520\|退回\|退]` | 显示成「已退还」|
| 图片 | `[图片：这里写图片描述]` | 图片卡片 |
| 定位 | `[定位：1.2km\|正在靠近你]` | 位置卡片，带雷达动画 |
| 天气 | `[天气：晴转多云\|记得带伞]` | 天气卡片 |
| 表情 | `[抱抱]` | 直接发表情包 |
| 旁白 | `[旁白：他抬头看了眼窗户。]` | 居中的斜体旁白 |

竖线是分隔符，中英文的 `|` `｜` 都认。

**内置表情**（直接写 `[名字]`）：

> 害羞、眼巴巴看着你的小狗、一只淋雨小狗、委屈、生气、心虚、我想你、睡觉、疑惑、
> 不满、觉得对方坏、摸头、分析局势、这是什么情趣、亲亲、网络把我毁了、我没招了、
> 翻白眼、吃饭、挠挠下巴、被爱意击中、咬你、抱抱、晚安、我超超超爱你、舔你、装货、
> 觉得对方犯贱、觉得所有人无语、觉得对方很欠揍、觉得自己帅、又咋了

也可以在设置里加自己的表情包，填个名字和图片链接就行。

## 旁白模式

**关着**的时候，聊天就是纯气泡对话，跟真的微信一样。

**开着**的时候，气泡之间会穿插旁白，写角色此刻的心理活动、小动作或者环境：

> 「手指悬停在键盘上，盯住那行灰色小字。」

三档可选：**跟随上一层** / **开** / **关**。可以整张卡统一设，也可以某个人单独设。

---

## 设置是分层的

同一个东西可以在三个地方设，**上面的盖下面的，留空就往下一层要**：

```
① 联系人专属   聊天界面右上角 ⋯      只管这一个人，跟着本轮聊天
② 这张卡的设置  设置页上半段          只管当前这张角色卡
③ 所有卡通用    设置页下半段          所有角色卡共用
```

| 设什么 | 在哪 |
|---|---|
| TA 的头像、聊天壁纸、朋友圈封面、在线状态、旁白 | ①② 都能设 |
| 名字、人设、群成员 | 只在 ① |
| 我的头像、字体、功能区图标、表情包 | 只在 ③ |

所以在 A 卡里换头像不会影响 B 卡。想让某个 NPC 有自己专属的壁纸，进那个人的 ⋯ 里设。

功能区那排图标也能换成自己的图：设置 → 功能区图标，每个功能填一个图片链接，
留空就用自带的。

## 和正文联动

默认开着。AI 在正文里写这样一段的时候：

```
[手机|在线|22:03]
[对|睡了吗]
[旁白：他把笔放下，盯着对话框看了一会儿。]
[对|没睡的话 下楼]
[/手机]
```

这段会被**搬进小手机**，正文里那段抹掉，悬浮球亮红点。点开就能看到 TA 发来的消息。

`[手机]` 后面的 `|状态|时间` 有没有都行。`[对|…]` 是 TA 说的，`[旁白：…]` 是旁白，
`[我|…]` 是你说的（如果和你刚发过的话重复，会自动跳过，不会存两遍）。

这样做的好处：

- **不额外花钱** —— 那段内容本来就是正文生成的一部分
- **和剧情同步** —— TA 找你是因为剧情里发生了什么，不是凭空触发
- **不影响别人** —— 没装这个扩展的人，那段会照旧留在正文里，用正则渲染也好、直接看也好，
  体验和以前完全一样。同一张角色卡，两边都能用

**只搬消息行，不动叙事。** 模型经常把大段描写直接写在 `[手机]…[/手机]` 里面：

```
[手机|思考中|17:21]
[对|不想来就不来]

他将手机倒扣在桌面上，视线落回那张做了一半的试卷。   ← 这段留在正文

[对|想吃大闸蟹吗]
[/手机]
```

方括号那几行进手机，中间的叙事原样留在正文里。块外面落单的 `[对|…]`（预设漏写
收尾标签时会出现）也会一并收走，不会在正文里留下一串裸露的方括号。

同一楼层 swipe 重 roll 不会重复搬运。

设置里可以单独关掉「抹掉正文里那段」，这样正文和手机里都保留一份。

### 你发的消息

你在手机里说的话**不会占正文楼层**（不然聊十句正文就多十楼，剧情节奏全碎了），
但会**实时告诉主线**：

```
正文：  TA「吃饭了吗」          ← 被搬进手机，正文里看不到
手机：  你「吃了，你呢」          ← 不占楼层
正文：  TA「刚开完会，饭都凉了」  ← 接得上，因为你那句已经告诉主线了
```

不用等记忆回流总结，你一发出去主线立刻就知道。在设置里可以调告诉主线最近几条，或者整个关掉。

## 记忆回流

上面的「实时告诉主线」管的是最近几条。聊得多了之后，更早的内容会被自动总结成梗概，
一起注入主线，角色就不会在正文里装作没聊过。

- **开关和频率**：设置 → 记忆回流
- **立即总结并回流**：手动触发一次
- **清空手机记忆**：把已经存的梗概清掉（聊天记录不动）
- 只统计和**主角色**的那条聊天，NPC 和群聊的私聊不会写进主线

### 用强预设的话（重要）

如果你用的是 ECoT、越狱类的强预设，请务必在
**设置 → 记忆回流 → 「工具调用走哪个接口」** 里选一个酒馆的连接配置
（Connection Profile）。

原因：总结记忆这种请求本来会带着你的预设一起发出去，强预设会把它当成剧情续写，
回一整篇小说过来。选了独立接口之后，这类请求会绕开预设和聊天历史单独发。
**聊天回复不受影响**，还是走你的预设，角色语气不会变。

没有连接配置的话，去酒馆的 API 连接页建一个，随便挂个便宜模型就够用。

### 越狱前缀

有些越狱预设和中转会让模型在回复开头先说一句无关的英文来绕过拒答
（`lol fuck off, anyway—` 这种）。这种开头会被自动丢掉，不会变成一条聊天消息
或者一条朋友圈。判断收得比较紧：只丢开头、不含中文、不含方括号、后面确实还有中文的行，
所以英文表情包、`[语音：…]`、整条英文回复都不受影响。

## 把设定打包进角色卡

设置 → **打包进角色卡** → 「把手机设定写进这张卡」。

会把联系人、群聊、头像、壁纸、在线状态、人设这些写进角色卡文件里，
导出卡的时候跟着一起走。别人导入你的卡、开一个新聊天时会自动铺上。

- **不含**聊天记录
- **不含**你自己的头像（别人的头像该是别人自己的）
- 已经有联系人的聊天不会被覆盖
- 「从卡里读回预设」可以把当前聊天重置成卡里那套

## 一些说明

**聊天记录存在哪**：跟着本轮酒馆聊天走。换一个聊天，联系人和记录就是新的一套，
互不干扰。

**在线状态**：角色可以自己改——TA 在 `[手机|出门中|17:25]` 里报的状态会显示在顶栏并保留。
你在专属设置里手动填的那个是底下一层，不会被吃掉；想拿回控制权，进那个人的 ⋯ 保存一次就行。

**时间是剧情时间，不是你电脑的时间**：AI 在 `[手机|出门中|17:25]` 里报的时间当基准，
之后每发一条自然往前走一两分钟——TA 25 分发的，你回就是 26、27 分。下次 AI 报了新时间就重新对齐。

带日期也认：`9/15 17:25`、`9月15日 17:25`、`2026-09-15 17:25`。

不写日期又比上一条早的时候，挑跨度小的那个解释：23:50 之后报 00:10，加一天才差
20 分钟，那就是真跨了午夜；17:38 之后报 17:28，加一天要差 23 小时 50 分，
那就是模型报偏了，时间顺着走，不会凭空多出一天。

「昨天」「9月10日」这些是相对**剧情里的今天**算的，不是现实日期。
AI 从没报过时间的话，退回用现实时间，两套时间各走各的不会混。

装这个功能之前的老消息用的是现实时间，和新消息接在一起会有一处跳变。
觉得乱就点设置里的**「重排：清掉已有消息的剧情时间」**，全部先按现实时间显示，
等 AI 下次报时间再重新对齐。消息内容不动。

**头像壁纸都是链接**：填图片的网址就行，本地图片得先传到图床。

**手机端**：面板会自动铺满屏幕，键盘弹出时也会重新排版。

**悬浮球不见了**：酒馆的扩展设置面板里有个「显示『星星小手机』悬浮球」的开关。
