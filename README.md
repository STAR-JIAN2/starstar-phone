# 星宝的小手机 · v0.12.0

SillyTavern 扩展。给角色装一部小手机：聊天列表、多 NPC、群聊、朋友圈，
消息支持语音 / 转账 / 外卖 / 定位 / 天气这些卡片，还能把手机里聊的内容回流到主线剧情。

## 安装

酒馆 → 扩展（插头图标）→ **Install extension** → 粘贴这个仓库地址：

```
https://github.com/你的用户名/tavern-phone
```

装完刷新页面，右下角会出现一个悬浮球，点开就是小手机。

> 如果你之前手动放过 `public/scripts/extensions/third-party/tavern-phone/`，
> **先把那个文件夹删掉**再装，否则会撞名字。

## 更新

扩展列表里点这个扩展的 **Update** 按钮就行（它会 git pull）。

## 用法速览

| 在哪 | 干什么 |
|---|---|
| 悬浮球 | 点开小手机，可拖动 |
| 聊天列表右上角 ＋ | 加联系人 / 发起群聊 |
| 聊天界面右上角 ⋯ | 这个人的专属设置（头像、壁纸、人设、旁白） |
| 底部「设置」 | 上半段管这张卡，下半段所有卡通用 |

设置是分层的，上面的盖下面的：

```
联系人专属（跟着本轮聊天）→ 这张卡的设置 → 所有卡通用 → 自带默认
```

## 用强预设（ECoT / 越狱类）的话

「设置 → 记忆回流 → 工具调用走哪个接口」记得选一个酒馆的连接配置。
总结记忆这种请求会绕开你的预设发出去，不然预设会把它当成剧情续写，
回一整篇小说过来。聊天回复不受影响，还是走你的预设。

# 更新记录

## v0.12.0：别让预设接管「工具调用」

**问题**：总结记忆、生成 NPC 这类请求是走 `generateQuietPrompt` 发的，而它会把请求
塞进你**当前的预设 + 聊天历史**里。强势的预设（ECoT / 越狱类）会直接无视
「输出150字摘要」，回一整篇小说过来——然后这篇小说被当成"手机记忆"存进世界书，
每轮注进主线。

**三层处理：**

1. **干净通道**（推荐）。设置 → 记忆回流 → 「工具调用走哪个接口」，选一个酒馆的
   连接配置（Connection Profile）。总结和生成 NPC 会走这个接口，**不带预设、不带聊天历史**。
   聊天回复不受影响，还是走你的预设——那儿本来就需要预设的角色语气。

   没有连接配置的话，去酒馆的 API 连接页建一个，这里就能选了。

2. **信封**。工具调用现在要求模型把结果放进 `<摘要>…</摘要>` / `<NPC>…</NPC>` 里，
   并在开头明确写"这是系统工具调用，不是剧情续写"。

3. **不合格就不用**。没有信封、又满是预设痕迹（`<Think>`、`<顶栏>`、状态栏、ECFR…）
   的返回，直接判失败，**宁可不更新记忆，也不把小说写进去**，并弹提示告诉你为什么。

   > 判断必须在剥壳之前做——`stripPreset` 会把一整篇小说洗成一段干净正文，
   > 洗完再判就看不出来了。

**顺带：**

- 记忆区多了「清空手机记忆」按钮。之前已经被写进去的脏摘要，点一下就没了
  （同时清掉主线注入和世界书里那条，聊天记录不动）。
- 让 TA 发朋友圈也加了同样的校验，模型回一大篇的话这条不会发出去。
- 控制台自检多了一行 `干净通道:✓(N个配置)`。

## v0.11.2：旁白终于看得见了（配合 ECoT 类预设）

两个都是「预设把回复包了一层壳」引起的。

**1. 手机块里的旁白被丢掉了**

预设输出成这样时：

```
[手机|盯着屏幕|08:38]
[我|咋回事]          ← 复述用户的，本来就该丢
[对|没睡好。]
[旁白：手指悬停在键盘上。]   ← 以前这行被丢了
[对|撤回了什么。]
[/手机]
```

旧的解析只捡 `[对|…]`，`[旁白：…]` 直接扔掉。所以旁白开着、模型也老实写了，
手机上就是看不见。现在手机块里的 `[旁白：…]` 会和气泡按原顺序一起渲染。

块**外面**的 `[旁白：…]` 仍然不搬进手机——那些是主线小说正文（人物上电梯、敲门…），
搬进来会把手机刷屏。手机块里的才是手机里的。

**2. 思维链和状态栏会被当成聊天内容 / 记忆摘要**

`<Think>`、`<顶栏>`、`<content>`、`[V9_DAILY_START]…[V9_DAILY_END]`、
`<!-- 当前字数 -->` 这些现在会在解析前统一剥掉。

影响最大的其实是**记忆回流**：以前摘要拿到的是整段带思维链的小说（两三千字），
然后每轮都注进主线。现在先剥壳，再封顶 400 字，超了会在控制台警告。
让 TA 发朋友圈、AI 生成 NPC 也一样先剥壳。

> 剥壳对没有预设的普通回复不做任何改动。

## v0.11.1：悬浮球头像跟聊天里对齐

悬浮球（点开小手机的那个图标）用的是**当前打开那张角色卡**的 TA 头像，换卡就换脸。

但之前它只认「设置 → 这张卡的设置」那一层，**不认联系人专属设置**——
所以你要是在聊天右上角 ⋯ 里单独给主角色换了头像，会出现聊天里是新头像、
悬浮球还是旧头像的情况。现在统一了，走同一条优先级链：

```
主角色的联系人专属设置 → 这张卡的设置 → 所有卡通用 → 自带默认
```

在专属设置里改完保存，悬浮球立刻跟着换。

## v0.11.0：头像壁纸不再串卡

**问题**：以前「设置」页是酒馆的用户级设置，不分角色。在 X 卡里换了 TA 的头像，
打开 J 卡一看，J 也变成那个头像了。

**现在**：设置页明确分成两段。

| | 存在哪 | 换卡会串吗 |
|---|---|---|
| 🎴 这张卡的设置<br>TA 的头像、聊天壁纸、朋友圈封面、在线状态、默认旁白 | 按角色卡分开存 | 不会 |
| 🌐 所有卡通用<br>我的头像、字体、功能区图标、记忆回流、表情 | 一份共用 | 会（本来就该共用） |

分卡是按角色卡的文件名认的（酒馆里这个最稳），拿不到就退回角色名。

完整的优先级现在是四层，上面的盖下面的：

```
联系人专属（聊天右上角 ⋯，管一个人，跟着本轮聊天）
  ↓ 留空就问
这张卡的设置（设置页上半段，管这张卡）
  ↓ 没设过就问
所有卡通用的默认值
  ↓
扩展自带的默认值
```

> **升级后要做一次的事**：每张卡第一次打开时，会把你现在的设置复制一份当起点。
> 所以如果你之前把 TA 的头像设成了 X 的，那 J 卡一开始也还是那个头像——
> 进 J 卡的设置改一次就行，改完两张卡就彻底分开了，以后互不影响。

## v0.10.0：群聊 · 主角色置顶 · 设定能跟着卡走

**群聊。** 会话列表右上角 ＋ → 「👥 发起群聊」，勾选谁进群，取个名字就行。

- 群里每条消息都标着是谁说的，头像也是各自的
- 让群里的人接话时，会把所有成员的人设一起喂给 AI，它可以一个人说，也可以几个人你一言我一语
- 群头像不设的话，自动用成员头像拼一个
- 群的专属设置（右上角 ⋯）里可以随时加人踢人、改群名、改群壁纸、单独开关旁白

**主角色永远置顶。** 其余联系人和群按最后一条消息的时间排。

**设定能打包进角色卡了。** 通用设置 → 「打包进角色卡」：

- 「把手机设定写进这张卡」会写进卡的 `data.extensions.tavern_phone`，导出 PNG/JSON 时跟着走
- 带的是**设定**：联系人、群聊、头像、壁纸、在线状态、人设、旁白开关
- **不带聊天记录**，也**不带你自己的头像**（别人的头像应该是别人自己的）
- 别人导入这张卡、开一个新聊天时会自动铺上；已经有联系人的聊天不会被覆盖
- 你自己也能用「从卡里读回预设」把当前聊天重置成卡里那套

> 写卡需要酒馆给扩展暴露 `writeExtensionField`。装好后看控制台那行自检日志里的
> `写卡接口 writeExtensionField:✓/✗`，是 ✗ 的话按钮会直接告诉你不支持。

## v0.9.0：多 NPC · 聊天列表 · 分层设置

**聊天变成两层了。** 点「聊天」先看到会话列表，点某个人才进对话界面。

- 列表默认只有主角色（名字头像跟着角色卡走），右上角 ＋ 自己加联系人，也可以点「✨ 让 AI 想一个」——
  AI 按当前剧情编一个名字/状态/人设填进表单，你改完再创建。
- 每个人一条独立的聊天记录，互不干扰。列表里有最后一条消息的预览和时间。
- NPC 回复时会把 TA 的人设喂给 AI，并说明「TA 不是主角色」。
- 联系人和聊天记录都跟着本轮酒馆聊天走（和以前的手机聊天一样按聊天隔离）。
- 老版本的聊天记录会自动迁移到「主角色」那条会话，不用管。

**设置分成两层：**

| | 在哪 | 管什么 |
|---|---|---|
| 通用设置 | 底部「设置」 | 所有人共用的默认值 |
| 专属设置 | 聊天界面右上角 ⋯ | 只管这一个人，留空就用通用的 |

专属设置里可以单独设：名字、TA 的头像、我在这个聊天里的头像、这个聊天的壁纸、在线状态、
旁白模式（跟随通用／开／关）、TA 的人设。

**旁白模式**：开了的话，除了聊天气泡还会有旁白（TA 的心理活动、环境描写）；关了就是纯气泡对话——
而且 AI 要是不听话硬塞旁白进来，会被直接滤掉。

**其他：**

- 功能区图标换成贴图了，不再是 emoji。想换成自己的图：通用设置 → 功能区图标，每个功能填个链接，留空就用自带的。
  （「链接」那个还缺一张贴图，现在临时用了一段同色系的手绘 SVG，你给我图我就换上。）
- 消息加了时间戳：距上一条超过 5 分钟就插一条居中的时间；聊天列表右侧显示最后一条的时间。
- 悬浮球缩小了（电脑端 54→42，手机端 48→38）。
- 记忆回流只统计和主角色的那条聊天，NPC 私聊不会写进主线。

## v0.8.3：手机端面板只剩顶部一条粉边的修复

手机上点头像展开后，手机壳塌陷成顶部一条（电脑端正常）。原因：移动端面板用的是
`top/bottom + height:auto`，部分手机浏览器内核会把里层的 `height:100%` 解析成 0。

- 移动端改为给出**明确的像素宽高**，并用 `!important` 写入，防止酒馆主题 CSS 覆盖。
- 手机壳 / 内容层改用四边定位撑满，不再靠百分比高度逐层传递。
- 新增自愈兜底：开面板后如果壳子高度仍不对，自动把像素宽高写死。
- 监听 `visualViewport`：键盘弹出/收起、横竖屏切换时重新排版。

## v0.8.2：回流"送到了但AI没当回事"的修正
从你贴的主线请求日志能确认：摘要**确实注入进了主线上下文**（世界书那条 + 直接注入那条都在），你的酒馆两个接口都正常。问题是那两行埋在 3.9 万 token 的大卡里、位置太深、语气太软，AI 没理会。这版针对性改：
- **注入位置从 depth 4 提到 depth 1**——紧贴当前楼层，就在你这句话上面，AI 最难忽略。
- **语气从"可自然衔接"改成硬要求**："郗昭理应清楚记得下面的内容，绝不能表现得毫不知情"。
- **带上最近 8 条手机原文**（不只是压扁的梗概），这样角色能记起具体的话、甚至你发的表情，而不是只有一句概括。
- **去掉重复注入**：既然你的世界书接口也好用，之前是"世界书 + 直接注入"两条都在灌同一段（你日志里能看到重了）。现在改成——直接注入成功时，世界书那条只当**可查看存档**（不再重复注入）；只有直接注入不可用时，世界书才顶上当兜底。

一个坦白：上次那个测试用例其实不好——你手机上聊的"等等我/在楼下"跟你下楼见他是同一件事，就算他记得也没啥可说的。建议这样测：手机上聊个**具体的、跟当前场景无关的事**（比如"我想吃草莓蛋糕"），再下楼问"你还记得我想吃啥吗"，他答得出=通了。

## 这版修了什么（对应你上轮反馈）
1. **语音快捷指令截断** —— 根因是模板里的 `"` 把 HTML 属性提前闭合了。已对属性做转义，模板完整填入。
2. **小窗看不到手机** —— 悬浮球改成**可拖拽**（按住拖到任意位置，点一下才是开/关）；面板打开时按视口重新定位，永远落在可视区内；层级拉满。
3. **我方组件嵌套气泡** —— 根因是你手机发的是带方括号的 `[代付：…]`，被当成纯文字塞进气泡又渲了张卡。现在统一先剥外层方括号再判类型，我方/对方都不再套气泡。
4. **撤回消息** —— 改成微信式：居中显示「你撤回了一条消息 / 对方撤回了一条消息」，**不带头像**（想看撤回内容点一下展开）。
5. **表情面板错乱** —— 改成固定 5 列、行高固定的并排网格，不再叠一起。
6. **删除单条** —— 鼠标悬在任意一条消息上，边上出现 ✕，点它删掉这条（发错了能撤）。
7. **对方回复一次性全弹** —— 改成**逐条延迟弹出**，每条前先「正在输入…」，像真人一条条发。
8. **AI 复述你的消息** —— 你角色卡的线上规则会让 AI 输出完整 `[手机]` 块（含 `[我|..]`）。现在渲染层**只认 `[对|..]`、忽略 `[我|..]`**，不管它复不复述都不会重复。
9. **在线状态** —— 设置页新增「TA 的在线状态」可手动填；AI 若按 `[手机|状态|时间]` 输出，状态字段也会更新到顶栏。
10. **全局挂着 / 会不会冲突** —— 数据是**按聊天隔离**的（存在各自聊天的 metadata 里），玩别的卡不会串。显示上：酒馆「扩展」面板里新增了一个「显示悬浮球」开关，玩别人卡不想看到手机时，去那里取消勾选即可（那里始终能点到，不会像手机里的开关那样被自己关死）。

## v0.7 新增：记忆回流主线（手机 ↔ 主线打通）
以前是单向的——主线上下文会带进手机（`generateQuietPrompt` 自带），但主线不知道手机聊了啥。现在反向也通了。

**怎么运作：**
1. 手机每聊够 N 条（设置里可改，默认 6 条），后台悄悄让 AI 把新消息**总结成一段第三人称剧情记忆**（150 字内，不复述原话）。
2. 这段记忆写进一条**蓝灯常驻**（`constant`）的世界书条目里——蓝灯 = 每次生成都注入，所以放下手机回到主线，AI 永远看得到手机上发生了啥、约定了啥、情绪怎么变了。
3. 摘要是**滚动更新**的：每次总结都把新消息并进旧摘要，只保留一条，不会越堆越多撑爆上下文。

**写到哪本世界书（设置里选）：**
- `本轮聊天专属`（默认，推荐）：和手机聊天一样按当前聊天隔离，存进这轮聊天的 chat-bound 世界书（没有就自动建一本 `📱小手机记忆-<角色名>` 并绑上）。**换一轮新剧情 = 干净的手机 + 干净的记忆，不会串。玩别人的卡也不会污染人家的角色卡。**
- `角色主世界书`：写进角色自己绑的世界书（跨所有和 TA 的聊天都记得）。角色没绑世界书时会自动退回“本轮聊天专属”，绝不擅自改坏卡。

**手动触发：** 设置页底部「立即总结并回流」，随时把当前手机聊天同步过去。上面那行状态字会显示同步到第几条、写进了哪本书、摘要开头。

**不想用：** 设置页「开启记忆回流」关掉即可（玩别人卡时嫌它多调一次 API 可以关）。

### 🌸 朋友圈（纯文字配图版，没上 NovelAI）
按你说的——不搞生图，配图直接写文字描述，简单又有手机味。
- **发一条**：朋友圈右上角 ＋，写想法。配图直接在正文里用方括号写描述，如 `今天天气好好 [窗外的晴天] [路边的猫]`，会渲染成小图卡（描述当图片名字看）。名字若正好是某个表情，就直接显示那张表情图。
- **让 TA 发**：右上角 `TA` 按钮，调 API 让角色按当前剧情/性格发一条朋友圈（也会用 `[描述]` 配图）。
- **互动**：你的帖子上有「让TA看」——调 API 让角色决定点赞/评论/都做/都不做；任何帖子你都能点 ♡ 赞、点 💬 评论；✕ 删帖。
- **封面**：设置页「朋友圈封面链接」可换，右下角是你的头像。
- 朋友圈数据和手机聊天一样**按聊天隔离**（存 `chatMetadata.tp_moments`），换轮聊天各是各的。
